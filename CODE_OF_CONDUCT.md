# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, give and accept constructive feedback, and no harassment of any kind.

To report a concern, use a private GitHub Security Advisory on this repository or contact the maintainer through their GitHub profile. Reports are handled confidentially.
