# Profile: Colombia (accessibility)

Optional profile for `ux-review`. Enable by adding the standard to `.devflow.yml`:

```yaml
a11y:
  standards: ["WCAG 2.2 AA", "NTC 5854"]
output_language: es
```

When enabled, the review adds a column mapping each WCAG criterion to its NTC 5854 equivalent and notes
the Colombian regulatory context (MinTIC web accessibility requirements for public entities).
Verify equivalences against the current official texts before citing them in a formal conformance report.
